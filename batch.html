适合这些情况

  1. 相册、资料包几十张图要统一压小再上传网盘或 CMS。
  2. 一批导出图要转成统一格式（如都转 WebP 或 JPG）。
  3. 部分失败不想整批重来，只要重试失败项。
  4. 处理完打包成一个 ZIP 发给同事或归档。
  5. 敏感截图批量处理，不愿上传到云端压缩服务。

怎么用

  1. 一次拖入多张 PNG / JPG / WebP（可粘贴）。
  2. 选择「压缩」或「转换」，设好质量/等级或目标格式。
  3. 处理完成后：逐张下载，或打包 ZIP；失败项单独重试。

为什么用 imagec

  • 批量压缩与格式转换同页完成，本地处理不上传。
  • 支持失败重试、单张下载与 ZIP 打包。
  • 与单张 /compress 分工清晰：多图走 batch，单张精调走 compress。

常见问题

批量压缩会上传图片吗？
不会。多图都在浏览器本地处理。
一次能处理多少张？
受设备内存与浏览器限制；建议分批，若卡顿就减少单次数量。
压缩和转换有什么区别？
压缩侧重减小体积；转换可输出 PNG / JPG / WebP / BMP 等目标格式（以页面选项为准）。
失败了怎么办？
可对失败项单独重试，不必清空全部重来。
和「在线图片压缩」页怎么选？
单张要仔细预览用 /compress；多张、要 ZIP 用本页 /batch。
